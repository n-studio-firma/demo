## 4. LP制作方針

### 4-1. 設計思想

> **「説明」ではなく「体験」**
> **「納得させる構造」で設計する**

- ストーリー → 理由 → 価値 → 導入の流れで構成
- 文字は少なく、写真主役
- 余白を命とする

### 4-2. 重視ポイント

| 優先度 | ポイント | 方針 |
|--------|---------|------|
| ★★★ | ブランドの世界観・高級感 | 黒マット×ゴールド、ミニマル、余白を活かしたラグジュアリートーン |
| ★★★ | 問い合わせ・資料請求のCV数 | セクションごとにCTAを配置、導線を明確化 |
| ★★★ | スマホ最適化 | モバイルファーストで設計、タップしやすいUI |
| ★★★ | 動画・アニメーション演出 | スクロール連動アニメーション、テクスチャー動画の活用 |

### 4-3. トーン＆マナー

| 項目 | 仕様 |
|------|------|
| デザインコンセプト | 「黒 × 静寂 × エネルギー」 |
| カラー配分 | 黒 80% / ゴールド 10% / 余白 10% |
| ベースカラー | マットブラック（#0B0B0B） |
| アクセントカラー | ゴールド（箔 or メタリック調） |
| サブテキストカラー | ウォームグレー |
| 英語ロゴフォント | セリフ体（例：Trajan / Cinzel / Playfair Display） |
| 本文フォント | サンセリフ体（ミニマル） |
| 写真トーン | 低彩度・ダーク基調、光と影のコントラスト |
| アイコン | 線のみ（ゴールド） |

### 4-4. デザインNG事項

- クレイ画像（泥感のあるビジュアル）
- ゴチャゴチャした説明テキスト
- 効果効能の直接的表現
- 安っぽいストック写真
- 彩度の高い色使い

## 10. 薬機法・景品表示法への注意

### 10-1. 薬機法

- 化粧品の効能効果の範囲を超える表現は不可
- NG例：「治る」「細胞が活性化する」「血行促進」等の断定表現
- 遠赤外線の効果を謳う場合は医療表現にならないよう柔らかい表現に留める
- 「98% 遠紅外線」等の数値使用はエビデンスの裏付けが必須

### 10-2. 景品表示法

- 優良誤認・有利誤認にあたる表現は不可
- Before/Afterは体感ベースの表現に留める

### 10-3. チェック対象セクション

| セクション | 注意ポイント |
|-----------|-------------|
| ③ 差別化 | 遠赤外線・細胞活性等の表現 |
| ④ ビジュアル訴求 | Before/After、効果実感の表現 |
| ⑥ 開発者ストーリー | 「皮膚科でも改善しなかった」等の体験談表現 |
